## 🛣️ ROADMAP — Veragent

> Verifiable, paid AI agents over HTTP
No accounts. No API keys. No subscriptions.



This roadmap follows the open‑standard, protocol‑first style used in the x402 (Coinbase) repository. It is intended to be public, iterable, and contribution‑friendly.


---

🌐 Vision

Veragent is the identity and payment layer for AI agents on the web.

As AI systems evolve from chatbots into autonomous agents, they require:

native payments (not SaaS billing)

verifiable identity

permissioned execution

open interoperability


Veragent makes AI agents first‑class, paid HTTP services.


---

🧱 Phase 1 — Foundation (MVP → Alpha)

Status: 🟢 Completed

Goals

Prove the core protocol loop

Ship a live, demo‑able MVP

Validate x402 + ERC‑8004 integration


Deliverables

[x] Veragent Gateway (HTTP + x402)

[x] ERC‑8004 agent identity & permission registry

[x] Agent runtime integration (OpenClaw)

[x] Marketplace UI (basic discovery + playground)

[x] Example agents (DeFi Monitor, Contract Explainer, Web Scraper)

[x] Protocol‑grade README & onboarding docs


Success Signals

Paid HTTP requests executed end‑to‑end

External developers able to run agents without accounts or API keys
